# Фотографии пары

Положите сюда файлы фотографий (рекомендуется WebP или JPEG, длинная сторона 1600–2400 px,
вес до ~400 КБ) и укажите их в `src/data/wedding.ts` → `photos`.

Путь указывается относительно этой папки `public/`, например `photos/hero.webp`.
Префикс GitHub Pages (`/<repository-name>/`) добавляется автоматически.
